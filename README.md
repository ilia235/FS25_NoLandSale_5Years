Мод для Farming Simulator 25 на заборону продажу земельних ділянок

Налаштування мода для збільшеня чи зменьшеня терміну блокіровкі продажу.

Відкрийте папку гри: Перейдіть туди, де знаходяться ваші збереження (savegame).
Зазвичай це шлях:
Документи \ My Games \ FarmingSimulator2025

Знайдіть папку налаштувань: У цій папці знайдіть і відкрийте папку (modSettings.)

Папка мода: Всередині modSettings гра автоматично створила папку з назвою вашого мода — (NoLandSale5Years.)
 Відкрийте її.

Відкрийте файл конфігурації: Ви побачите там файл (config.xml). Натисніть на нього правою кнопкою миші та виберіть "Відкрити за допомогою" -> Блокнот (або будь-який інший текстовий редактор, наприклад, VS Code чи Notepad++).

Змініть значення: У файлі ви знайдете такий рядок:
<blockedYears>5</blockedYears>


Просто замініть цифру 5 на будь-яку потрібну вам кількість років (наприклад, 10, 3 або 1).

Збережіть файл: Натисніть Ctrl + S (або Файл -> Зберегти) і закрийте Блокнот.

Важливий нюанс: Робити ці зміни найкраще тоді, коли ви повністю вийшли з гри (або хоча б вийшли в головне меню). При наступному завантаженні вашого збереження мод прочитає нову цифру з цього файлу і застосує її!
